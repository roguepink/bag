## 縫製の目でもう一度(通しで読んだ)

- **まいにちトート L**(12手順): 型紙 → 布に置いて切る → 印を写す → 持ち手 → 内ポケット → マグネット → 表袋 → マチ → 裏袋(返し口)→ 持ち手の仮どめ → 口を縫う → 返して縫いおさえ。**抜けも矛盾もない。**
  小さな点: 手順 10「持ち手のはしを口の切り口から1cm出して」— 出た所は縫ったあとに切りそろえる、と一言あると親切。手順 5 の内ポケットは「わ(口)を上にして、左右と底を縫いつけ」と向きを書くとよい。
- **ミニボストン M**(12手順): 接着芯 → 持ち手 → ファスナーで筒 → Dカン通し → 「ファスナーを半分あけておく」→ 横を縫って返す → 裏袋 → まつる。順番は正しい。
  **抜け 2つ:** ① 肩ひもの作り方が無い(用意するものに「肩ひも 〇cm(市販でもよい)」とあるだけで、手作りする人の手順が無い)。「市販のナスカン付き肩ひもを使う」と書くか、肩ひもの手順を足す。
  ② 手順 12「裏袋を表袋の中に入れ」— 裏袋は**裏返しのまま(縫い代が外がわ)**で入れる、と書かないと、縫い代が袋の中に見える向きで入れてしまう。担当: 型紙係 `js/bags/shoulder.js`
- **グラニー M**(12手順): 前回の3点が直り、**通しで作れる。** 小さな点: 内ポケットは「表布のあまりでもよい」と書いたが、用意するものの裏布は 70cm のまま(ポケットを表布で切るなら 35cm で足りる)。用意するものの裏布の横に「内ポケットを表布で切るなら 35cm」と添える。担当: 型紙係(materials の note)
- **ナップサック M**(11手順): ほつれどめ(手順 5)がわきを縫う前に入り、割る → コの字 → 三つ折り → ひもの順。**抜けも矛盾もない。**
  小さな点: 手順 9 で口の三つ折りの前に、わきのあきの所の縫い代の始末(手順 8 のコの字)が先に来ていて正しい。ひも 180cm × 2本も足りる。
