## 見つかった問題(重い順)

### ふつう

1. **型紙画面の全体図の文字が、スマホで とても小さい**(デザイン係 `js/ui-pattern.js` / 型紙係 `js/print.js` overviewSVG)
   30袋ぜんぶ。SVG の中の文字が画面で まん中 7〜11px、いちばん小さいと 2〜5px(巾着リュック・ボストン・バルーンなど パーツの多い袋)。
   お年寄りには読めない。「大きく見る」でも 最初は同じ大きさ。
   直し方: 全体図の下の「① 本体 表布1枚…」の一覧を SVG ではなく **HTML の文字(20px 以上)** で出す(overviewSVG に `{list:false}` を足す)。
   図の中は 番号の丸と パーツ名だけにして、`fontScale` を 1.6 くらいに。
2. **あずま袋(wa-azuma)の印刷: 1枚目に 5cm の四角がないのに、案内は「1枚目に四角があります」**(デザイン係 `js/ui-print.js`)
   あずま袋は型紙なし(布に直接線を引く)なので print.js はわざと四角を出していない。
   直し方: 型紙のパーツがない袋(pieces が全部 measureOnly)は、印刷の案内の「5cmの四角を測る」を出さない。
   いっそ「印刷は いりません。寸法の紙を1枚だけ印刷できます」と書く。
3. **1枚目の上 3分の1 が 説明だけで、型紙が下の段にずれ、ページが増える**(型紙係 `js/print.js` printPlan)
   例: まいにちトート L は A4 9枚(本体 59×45cm は 3×2=6枚で入る大きさ)。くったり大きなトート S と M が同じ 9枚。
   直し方: 説明と 5cm の四角を「小さいパーツ(ポケットなど)の横」に置けるか試す。または説明だけの 0ページ目を作り、型紙は A-1 から詰める(枚数が減るなら)。
4. **sw.js が「まず手もとの控え」なので、直した js が スマホに届かない**(デザイン係 `sw.js`)
   いま係が同時に直しているので、VERSION を上げ忘れると 古い型紙のまま。公開前に必ず VERSION を上げる。
   できれば js/css は「ネットを先に、だめなら控え」にする。

### 軽い

5. **左上の「バッグの型紙」(.brand)のリンクが高さ 39px**(デザイン係 `css/style.css`)。ボタン 64px の約束より小さい。押せる場所を 64px にするか、押せない飾りにする。
6. **作り方の画面の「もどる」で、型紙ではなく 印刷の画面にもどる**ことはない(OK)。ただ 見る→型紙→印刷→作り方 と来ると、もどる は 型紙へ飛ぶ(parentOf の決まりどおり)。問題ではないが、印刷から来た人には少しとまどうかも。
7. `js/bags/tote.js` の変数名 `toteFlat` が id `tote-basic`(まいにちトート)、`js/bags/pouch.js` の `poFlat` が `po-gama`、`outing.js` の `outEco` が `out-granny` など、**コメントと変数名と中身がずれている**(型紙係)。動きには関係ないが、直すときに取りちがえやすい。
8. `_check/` は .gitignore に入っている(OK)。

## 縫製の目での点検

### まいにちトート L(tote-basic・よこ42 × たて36 × マチ15cm)
- 寸法: 本体 よこ 57cm(42+15)× 43.5cm(36+7.5)、角を 7.5cm 四方切りとる → つまむと マチ 15cm・高さ 36cm。**合っている。** 縫い代 1cm、底のまん中・持ち手の位置に合い印あり。
- 抜けている手順:
  - **マグネットボタンを付ける時期が書いてない**(型紙に「マグネット(裏布)」の印はある)。手順 7(裏布を縫う)の前に「裏布の印に、接着芯を小さく貼ってマグネットを付ける」を入れる。
  - **持ち手の仮どめの向き**: 「持ち手を本体の表側に、下向きにたらして、ねじれないように」と書かないと、裏返したとき持ち手が中に入らない・ねじれる失敗が多い。
  - わき・底の縫い代を アイロンで割る(または片側に倒す)が無い。マチを縫う前にあると きれい。
- 持ち手の差しこみ 2cm に対し縫い代 1cm なので、持ち手のはしが口の布から 1cm 出る。「はみ出た所は口の布にそろえて切る」か、差しこみを縫い代と同じ 1cm に。
- 接着芯は「お好みで」なのに 型紙の印・用意するものに 量が出ない。使う人向けに「接着芯 幅90cm × 〇cm(お好みで)」を出すとよい。

### がま口ポーチ M(po-gama・口金 15cm)
- 縫い代 7mm、口の中心・あき止まり・ダーツに合い印あり。ダーツ → 底を縫う → 裏袋(返し口 6cm)→ 口を縫う → 切りこみ → 返す → 口金、の順は **正しい。** 最初に「お手持ちの口金に重ねて線をなおす」があるのも良い。
- 直したい所:
  - **接着芯を本体と同じ型紙(縫い代つき)で切る**ことになっている。縫い代に芯が入ると 口金のみぞに入りにくい。「接着芯は 細い線(できあがり線)で切る」と書く(トート系には この注意がある)。
  - 手順 9「口のまわりを縫いおさえます」は、**口金に差しこむ場合は縫わないことも多い**(厚くなって入らない)。「うすい布のときだけ」などにする。
  - 口金の大きさの合わせ方: 口金の「幅」は外寸か内寸かで 1cm ちがう。用意するものに「外寸 15cm」など、どこを測るかを書く。

### ナップサック M(bp-knapsack・35 × 42cm)
- 本体1枚(底が わ)、口の縫い代 3.5cm(1cm 折る + 2.5cm のひも通し)、あき止まり 7cm、底から 2cm にループの合い印。ひもは 180cm × 2本(口のまわり 70cm + 下まで 84cm + 結び しろ)で **足りる。** 手順の順番も 正しい(わきのあきを始末 → 口を三つ折り → ひもを通す)。
- 抜けている手順:
  - **裏布なしの袋なのに、縫い代の始末(ジグザグミシン・ほつれどめ)が無い。** 洗うと わきの布がほつれる。手順 5 のあとに「わきの縫い代2枚をいっしょにジグザグミシン(または割って片方ずつ)」。
  - ひも通し口の両はしは、わきの縫い代を割ったまま三つ折りにする、と書くとよい(厚みで縫いにくい所)。
- ループは できあがり 8 × 1cm。太さ 6mm のひも 2本(往復で4本)を通して結ぶには 少し細い。幅 1.5cm くらいにすると楽。

### グラニーバッグ M(out-granny・いちばん広い所 38 × 32cm)
- 本体 上の幅 45.5cm を 22cm に寄せる(約2倍のギャザー)、あき止まり 7cm、底の丸み、内ポケット付け位置、合い印あり。口布は 49 × 11cm を輪にして たて半分(できあがり 幅 4.5cm)、22cm が口・25cm が持ち手。**形として成り立つ。**
- 直したい所:
  - 手順 6「あき止まりから上のわきを…縫います」は、**左右・前後の 4か所**(前の右・前の左・後ろの右・後ろの左)を それぞれ 表布と裏布で縫う、と書かないと分かりにくい。あき止まりの縫い代に切りこみも要る。
  - 手順 3 の内ポケット: 型紙には「返し口を残して縫う」の印があるが、手順の文に返し口が無い(まいにちトートには ある)。そろえる。
  - 手順 10「口布の22cmの所で前の口をはさんで縫い」: 口布の輪の **縫い目(つなぎ目)を どこに置くか**(持ち手のまん中か、口のはしか)が書いてない。持ち手の内側のまん中に来るようにすると目立たない。
  - 用意するもの: 裏布 70cm は 表布(35cm)の倍。内ポケット 18cm(わ で 36cm)が本体の横に入らないため。内ポケットを「表布のあまり・はぎれでもよい」とすれば 裏布 35cm で足りる(materials の計算は正しい)。
