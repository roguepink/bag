# バッグの型紙

バッグの形を3Dで見てえらぶと、そのバッグの **原寸の型紙** が出て、家のプリンターで印刷できるアプリです。
大きな型紙は A4 を何枚かに分けて印刷し、貼り合わせて使います。70〜80代の方がひとりで使えるよう、文字は大きく、ボタンは少なくしています。

https://roguepink.github.io/bag/ (スマホのホーム画面に入れると、電波がなくても使えます)

## 使い方(5つの流れ)

1. **えらぶ** … 6つの仲間から、作りたいバッグをえらぶ(「かんたんなものだけ」の切りかえもあります)
2. **見る** … 3Dで回して見る。大きさ(小・中・大)と、布の柄・色をえらぶ
3. **型紙** … 全体図・パーツの一覧・用意するもの・紙の枚数を見る
4. **印刷** … パソコン/スマホ/コンビニのどれで印刷するかをえらび、案内どおりに印刷する
5. **作り方** … 1手順ずつ大きな字で。むずかしい言葉は、押すと説明が出ます

## 印刷のこつ

- 印刷の画面で **「実際のサイズ」または「100%」**(拡大・縮小しない)をえらぶ。「用紙に合わせる」は型紙が小さくなります。
- **まず1枚だけ** 印刷して、1枚目の **5cmの四角** を定規で測る。ちょうど5cmなら、残りを印刷します。
- 貼るときは、1枚目は切らずに置き、2枚目からは白いふちを点線で切って、となりの紙のななめの線(のりしろ)に重ね、◆を合わせて貼ります。
- 家にプリンターがないときは、PDFとして保存して、コンビニの印刷(ネットプリントなど)で「A4・等倍」で印刷できます。

## 作り

- ビルドなしの ES modules。`index.html` を開くだけで動きます。
- 3D は three.js r186 を `vendor/three/build/` に同梱(CDN を使わない)。柄は canvas で描き、3D は寸法から作るので、画像の素材はありません。
- 型紙の寸法はすべて mm。PWA(`manifest.webmanifest`・`sw.js`)で、一度開けばオフラインでも使えます。
- おもなファイル: `js/bags/*.js`(30種類の型紙と作り方)、`js/print.js`(印刷のページ)、`js/viewer3d.js`(3D)、`js/fabric.js`(柄と色)、`js/ui-*.js`・`css/style.css`(画面)。係ごとの約束は `CLAUDE.md` にあります。
